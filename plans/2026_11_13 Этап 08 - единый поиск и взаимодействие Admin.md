# Этап 08 - единый поиск и взаимодействие Admin

## Навигация и hover

В первой панели только иконки, без видимых названий; сохранить title и доступные имена, первая иконка «Сотрудники». Во второй статичный некликабельный заголовок «Оргструктура» и постоянно видимые Сотрудники/Организации/Подразделения/Должности, без details в том числе на мобильном.
Hover иконки меняет фон/цвет, hover второго меню — всю строку/цвет текста. Active отличается от hover, focus-visible, pointer только у действий. Переход150мс, reduced-motion отключает. Заголовок без hover.

## Один поиск

Удалить обновление и все фильтры над таблицей. Одно поле непосредственно над таблицей каждой сущности; название, новая запись и количество остаются. Поиск/страница отдельно для сущностей, ввод сбрасывает страницу, debounce300мс, устаревшие ответы игнорируются, пустой поиск возвращает все записи. Поля выбора связей в редакторах сохраняются.

## Вся карточка

Сотрудники: ФИО/части имени, код, кадровый логин, email, пол, даты, статус, data, логин и состояние доступа, текущие должности/подразделения/организации/центр затрат.
Организации: код/название/отображаемое название/data.
Подразделения: код/название/статус/расформирование/даты/организация/родитель/центр затрат/data.
Должности: код/название/статус/руководящая/даты существования и закрепления/сотрудник/подразделение/организация/типовая должность/data.
Идентификаторы доступны для поиска. Пароли/хеши/токены/сессии и история исключены. В JSON искать значения (включая вложенные и массивы), не ключи. Регистронезависимая подстрока, буквальные %, _, обратный слеш; ISO и русские даты, русские статусы и логические значения. Связи без дублей, одинаковые items/total, серверная пагинация. Фильтры API остаются для совместимости, UI их не передаёт. Новая миграция не нужна.

## Карточки

Двойной клик по всей tr, любой ячейке и пустому месту; одинарный не открывает. Убрать кнопку в первой колонке, строка фокусируема, Enter открывает. На touch отдельная команда открытия выбранной строки. Dialog/dirty/Escape/обновление сохраняются. Фокус обратно строке либо новой записи.

## Приёмка и поставка

PostgreSQL: все поля/JSON/связи/русские статусы/даты/регистр/спецсимволы, отсутствие дублей и утечки секретов. Firefox: один поиск, нет фильтров/обновления, статичное меню, иконки без подписей, hover/active/focus, dblclick ячеек и пустой области, одиночный клик не открывает, Enter/touch, сохранение состояния, Escape и фокус. Go -race, сборка Admin, браузерные регрессии. README/AGENTS, коммит и push после локальных проверок; Docker API/Admin и реальная серверная приёмка отдельно.
