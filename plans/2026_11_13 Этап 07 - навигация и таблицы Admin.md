# Этап 07 - навигация и таблицы Admin

## Результат и архитектура

NavigationRail 72 px: Оргструктура, Курсы, Тесты, Опросы, пользователь, выход и проверка API. SectionSidebar 240 px: Сотрудники, Организации, Подразделения, Должности. Workspace: toolbar, таблица, пагинация, полноэкранный редактор. Начальный экран — сотрудники. Учебные разделы показывают сообщение «Раздел находится в разработке». Старую внутреннюю трёхколоночную оргструктуру заменяют таблицы. Сохраняем цвета, формы, API и кадровую логику без новых библиотек и миграций.

## Таблицы

Состояние каждой таблицы отдельно в React: q, фильтры, page, limit. Закрытие карточки и переключение сущностей сохраняют состояние, перезагрузка сбрасывает. Поиск/фильтр сбрасывает страницу. Смена организации очищает подразделение. Пагинация серверная 25/максимум100, стабильная сортировка, items/total. Устаревшие ответы игнорируются.
Колонки сотрудников: ФИО/email/основная должность/подразделение/организация/кадровый статус; организаций: название/код/отображаемое название; подразделений: название/код/организация/родитель/статус; должностей: название/код/подразделение/организация/сотрудник или вакансия/статус.
Фильтры: кадровый статус; организация и статус подразделений; организация, подразделение, занятость и статус должностей.
После сохранения обновлять список с текущими фильтрами даже при исчезновении записи; окно остаётся открытым. При уменьшении страниц перейти на последнюю, пустой результат — первая.

## Карточки

Нативный dialog.showModal на весь viewport, фон inert, внутренняя прокрутка, доступное название. Одна форма для create/edit, переиспользовать кадровые операции, доступ, назначения и историю. Выбор связей — серверный поиск с пагинацией, без загрузки всех записей. Перенос существующих подразделений/должностей запрещён.
После save актуальные данные и точные updated_at без JS Date; список обновляется. 409 сохраняет ввод и предлагает подтверждённую загрузку актуального. Escape/cancel и закрытие проходят единую проверку dirty. Вернуть фокус в строку; если исчезла — в «Новую запись». Сеть не закрывает карточку, beforeunload защищает dirty.

## API и мобильная версия

Добавить q по названию/коду с буквальным экранированием %, _ и обратного слеша. Фильтр статуса подразделений и организации должностей. Несовпадение организации и подразделения — 400. Возвращать отображаемые имена связей без N+1 браузерных запросов. Авторизация и SQL-триггеры неизменны.
На мобильном переключатель разделов, раскрываемое меню сущностей, рабочая область во всю ширину. Прокрутка по горизонтали только внутри таблицы, dialog без отступов.
