# Правила именования планов

Имена файлов планов следуют образцу существующего плана:

`2026_11_13 Этап 4 - авторизация в Admin и Portal.md`

Шаблон: `ГГГГ_ММ_ДД Этап N - название этапа.md`.

- В начале указывай дату создания плана: год из четырёх цифр, месяц и день из двух цифр, разделитель — подчёркивание.
- После даты ставь пробел, слово «Этап», пробел и номер этапа без ведущего нуля.
- Номер и название разделяй обычным дефисом с пробелами: ` - `.
- Название пиши по-русски, сохраняя принятые технические названия, например Admin и Portal. Используй пробелы между словами.
- Используй расширение `.md` в нижнем регистре.
- Первый заголовок внутри файла должен соответствовать этапу и названию, без даты: `# Этап N — название этапа`. В заголовке используй длинное тире, как в текущем плане.

Эти правила относятся к файлам планов; файл инструкций называется `agent.md`.
